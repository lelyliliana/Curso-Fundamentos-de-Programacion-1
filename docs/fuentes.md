# Fuentes oficiales para consultar y profundizar

[Inicio](../README.md)

Estas referencias documentan el lenguaje y sus APIs. Los ejemplos del curso se escribieron para su propia secuencia didáctica. Al consultar documentación de otra versión, comprueba que la API exista en JDK 21.

| Área | Fuente |
|---|---|
| Lenguaje y aprendizaje | [Dev.java: Learn Java](https://dev.java/learn/) |
| Genéricos | [Dev.java: Introducing Generics](https://dev.java/learn/generics/intro/) |
| Colecciones | [Dev.java: Collections Framework](https://dev.java/learn/api/collections-framework/intro/) |
| Excepciones | [Dev.java: Exceptions](https://dev.java/learn/language/annotations-exceptions/exceptions/) |
| JDK 21 | [Documentación de Java SE 21](https://docs.oracle.com/en/java/javase/21/) |
| ArrayDeque | [API de ArrayDeque en Java 21](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/ArrayDeque.html) |
| Files | [API de Files en Java 21](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/nio/file/Files.html) |
| Streams binarios | [DataOutputStream](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/DataOutputStream.html) y [DataInputStream](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/io/DataInputStream.html) |
| Precisión decimal | [BigDecimal](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/math/BigDecimal.html) |
| JDK por plataforma | [Eclipse Temurin](https://adoptium.net/temurin/releases/?version=21) |
| Control de versiones | [Tutorial oficial de Git](https://git-scm.com/docs/gittutorial) |

Consulta primero el contrato de la operación: qué recibe, qué devuelve, si modifica la estructura y qué excepciones puede lanzar. Después relaciona esa información con el requisito que estás resolviendo. Una operación disponible no necesariamente es la elección correcta para tu dominio.
